# David Gallo | Portafolio

Portafolio personal single-page con diseño de "card gigante" interactiva que se revela con scroll. Estilo minimalista y elegante con tema oscuro/claro.

## Stack

- React 19 + Vite
- anime.js (animaciones)
- CSS Variables (temas y personalización)
- GitHub API (proyectos secundarios)

## Desarrollo local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
